ЧТО ЭТО
-------
Локальное приложение для ведения клиентов, договоров, генерации
документов из Word-шаблонов и контроля готовности рабочих
документов. Работает в собственном окне (без браузера).
Все данные хранятся только на вашем компьютере:
  • база данных — один файл  data\docflow.db
  • документы  — папки       clients\<Клиент>\<Год>\
  • шаблоны    — папка       app\templates\

Интернет для работы НЕ нужен. Ничего никуда не отправляется.

НОВОЕ В ВЕРСИИ 1.1.0
--------------------
• Договор без этапов: в форме убраны даты 1-го и 2-го этапов,
  вместо них — «Срок оказания услуг, раб. дней» (по умолчанию 20).
  Пункты 5.1/5.2 шаблона приведены к требуемому виду.
• «Оригиналы отчётности до» заполняется автоматически:
  за 5 рабочих дней до даты выдачи аудиторского заключения
  (если поле оставить пустым; субботу/воскресенье учитывает).
• Автозаполнение ФИО: после ввода «Колесников Игорь Николаевич»
  сами заполняются «Колесникова Игоря Николаевича» (в лице …)
  и «И.Н. Колесников» (для подписи). Работает и для подписанта
  в Настройках. Результат можно поправить вручную — автозамена
  перезапишет только пустые или ранее заполненные автоматически
  поля (очистите поле, чтобы обновить его автоматически).
• Матрица «Общий документооборот»: клик по ячейке со статусом
  открывает окно смены статуса (готов/подписан/отправлен/получен)
  прямо из матрицы.
• Новый раздел «Рабочие документы»: таблица готовности РД по
  договорам — кто из ассистентов готовит, кто из аудиторов
  контролирует, плановый срок сдачи, статус
  (не начат / в работе / на проверке / доработка / принят).
  Просроченные сроки подсвечиваются красным.


СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
• Windows 10/11 (64-bit).
• Компонент WebView2 — в Windows 11 уже встроен. Если приложение
  сообщит, что WebView2 не найден (редко, на Windows 10),
  установите «Evergreen Bootstrapper» с сайта Microsoft:
  https://developer.microsoft.com/microsoft-edge/webview2/
• ~700 МБ свободного места на диске.


УСТАНОВКА (3 шага)
------------------
1. Скопируйте архив DocFlow-1.1.0-win64.zip на компьютер и
   РАСПАКУЙТЕ его полностью в постоянную папку, например:
       D:\DocFlow\
   Важно: распаковать всю папку (app, runtime и т.д.), а не
   запускать файлы прямо из архива. Не рекомендуется
   Program Files — там могут мешать права.

2. Запустите  install.bat  (двойной клик).
   Он создаст папки данных и ярлык «DocFlow» на рабочем столе.
   Если SmartScreen спросит «Система Windows защитила ваш
   компьютер» → «Подробнее» → «Выполнить в любом случае»
   (программа без платного сертификата подписи — это нормально
   для внутреннего инструмента).

3. Запустите приложение: ярлык «DocFlow» или файл DocFlow.bat.

ОБНОВЛЕНИЕ С ВЕРСИИ 1.0.0
-------------------------
Закройте DocFlow, замените папку app\ новой из архива 1.1.0.
Папки data\, clients\, backups\ НЕ ТРОГАЙТЕ. База обновится
автоматически при первом запуске (добавятся новые поля и
разделы, старые данные сохранятся).


ПЕРВЫЙ ЗАПУСК — ЧТО ПРОВЕРИТЬ
-----------------------------
1. «Настройки»: реквизиты Исполнителя уже заполнены данными
   ООО «САИ» (подписант, доверенность № 205, страховой полис).
   Проверьте и поправьте при необходимости — они подставляются
   во все договоры.
2. «Настройки → Шаблоны документов»: тип «Договор» активен,
   шаблон «Договор_аудит.docx» встроен.


КАК РАБОТАТЬ (типовой сценарий)
-------------------------------
1. «Клиенты» → «＋ Новый клиент»: реквизиты, банк, руководитель.
   Введите ФИО руководителя полностью и нажмите Tab/кликните
   мимо поля — род. падеж и сокращение заполнятся сами.
   При сохранении создаётся папка клиента в репозитории.
2. Карточка клиента → «Контакты»: руководитель, гл. бухгалтер,
   контактное лицо.
3. «Договоры» → «＋ Новый договор»: номер предложится
   автоматически (маска 193/26-А), укажите дату, год, цену,
   % предоплаты, срок оказания услуг (раб. дней, по умолчанию
   20) и дату выдачи АЗ — дата предоставления оригиналов
   отчётности подставится сама (за 5 раб. дней до АЗ).
4. Создание документа: вкладка «Документооборот» → «Создать из
   шаблона» или раздел «Создать документ» (мастер). Файл
   сохраняется в clients\<Клиент>\<Год>\, статус «готов».
5. Статусы документов: в карточке клиента (вкладка
   «Документооборот») или кликом по ячейке в матрице «Общий
   документооборот»: готов → подписан → отправлен → получен.
   Каждое изменение пишется в «Историю».
6. «Рабочие документы»: добавьте строки РД по договору —
   раздел, ассистент, контролирующий аудитор, плановый срок.
   Статусы меняются прямо в таблице (выпадающий список).
   Фильтры: договор, статус, поиск. Имена ассистентов/аудиторов
   предлагаются из ранее введённых.


РЕЗЕРВНОЕ КОПИРОВАНИЕ
---------------------
• Кнопка «Сделать бэкап сейчас» в Настройках — копия в
  backups\<дата_время>\ (база + документы + шаблоны).
• backup.bat — то же из проводника.
• Автоматически каждый день в 23:00 — выполните один раз
  в командной строке (подставьте свой путь):

  schtasks /Create /TN "DocFlow Backup" /TR "\"D:\DocFlow\backup.bat\" silent" /SC DAILY /ST 23:00 /F

  Копии старше 30 дней удаляются автоматически.
• Восстановление: закройте приложение, верните docflow.db из
  бэкапа в data\ (и папки clients/templates при необходимости).


УДАЛЕНИЕ
--------
Удалите ярлык и папку программы целиком (сначала сделайте бэкап).

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
1. Запустите DocFlow-debug.bat — откроется консоль с текстом
   ошибки (сообщите его разработчику).
2. Окно открылось, но внутри красная плашка — на ней текст
   ошибки и путь к базе.
3. Антивирус ругается на pythonw.exe в папке runtime — добавьте
   папку программы в исключения: это портативный Python из
   официального дистрибутива.
4. Ничего не запускается — проверьте, что папка распакована
   полностью (app\, runtime\ с файлом pythonw.exe, bat-файлы).

Тесты для самопроверки (не требуют установки):
tools\test_backend.py, tools\test_migration.py, tools\test_template.py
