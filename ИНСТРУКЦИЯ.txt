ЧТО ЭТО
-------
Локальное приложение для ведения клиентов, договоров, генерации
документов из Word-шаблонов, контроля рабочих документов и общих
задач. Работает в собственном окне (без браузера).
Все данные хранятся только на вашем компьютере:
  • база данных — один файл  data\docflow.db
  • документы  — папки       clients\<Клиент>\<Год>\
  • шаблоны    — папка       app\templates\

Интернет для работы НЕ нужен. Ничего никуда не отправляется.

НОВОЕ В ВЕРСИИ 1.2.0
--------------------
• ВХОД ПОЛЬЗОВАТЕЛЕЙ: у каждого свой логин и пароль.
  При первом запуске нажмите «Регистрация» под кнопкой входа
  и создайте свою обычную учётную запись. Резервная учётная запись
  администратора admin сохраняется отдельно; после входа администратор
  может изменить роль зарегистрированного пользователя.
  После успешного входа приложение запоминает текущую учётную запись
  на этом компьютере и при следующем запуске входит автоматически.
  Кнопка «Выйти из приложения» отключает автоматический вход.
• АДМИНИСТРИРОВАНИЕ (видно только админу): раздел в меню слева —
  управление пользователями (создать, изменить имя/пароль/роль,
  отключить) и ЖУРНАЛ: кто когда входил и что делал в приложении
  (создание клиентов, договоров, генерация документов, смена
  статусов, задачи, настройки…). Журнал выгружается в CSV.
• КАЛЕНДАРЬ-ПЛАНЁР (общий для всех): сетка месяца как в Google
  Календаре; задача на дату с временем/дедлайном, ответственным,
  участниками и описанием; видно, кто добавил задачу. Панели
  «Ближайшие задачи» и «Мои задачи», отметка «выполнена»,
  подсветка просроченных. Изменить или удалить задачу может её автор
  или администратор.
• Все действия пишутся в журнал от имени текущего пользователя;
  авторство видно в статусах документов.

РАНЕЕ (1.1.0)
-------------
• Договор без этапов: «Срок оказания услуг, раб. дней» (20).
• «Оригиналы отчётности до» — автоматически за 5 раб. дней до АЗ.
• Автосклонение ФИО: ввели «Колесников Игорь Николаевич» —
  сами заполнились «Колесникова Игоря Николаевича» и
  «И.Н. Колесников».
• Смена статуса документа кликом по ячейке матрицы.
• Таблица «Рабочие документы»: ассистент / аудитор / срок / статус.


СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
• Windows 10/11 (64-bit).
• Компонент WebView2 — в Windows 11 уже встроен. Если приложение
  сообщит, что WebView2 не найден (редко, на Windows 10),
  установите «Evergreen Bootstrapper» с сайта Microsoft:
  https://developer.microsoft.com/microsoft-edge/webview2/
• ~700 МБ свободного места на диске.


УСТАНОВКА (3 шага)
------------------
1. Скопируйте архив DocFlow-1.2.0-win64.zip на компьютер и
   РАСПАКУЙТЕ его полностью в постоянную папку, например:
       D:\DocFlow\
   Важно: распаковать всю папку (app, runtime и т.д.), а не
   запускать файлы прямо из архива. Не рекомендуется
   Program Files — там могут мешать права.

2. Запустите  install.bat  (двойной клик).
   Он создаст папки данных и ярлык «DocFlow» на рабочем столе.
   Если SmartScreen спросит «Система Windows защитила ваш
   компьютер» → «Подробнее» → «Выполнить в любом случае».

3. Запустите приложение: ярлык «DocFlow» или файл DocFlow.bat.
   В окне входа нажмите «Регистрация», укажите свой логин,
   имя и пароль. После регистрации вход выполняется автоматически.
   Резервный вход администратора: admin / 25571555.

ОБНОВЛЕНИЕ С ВЕРСИЙ 1.0.0 / 1.1.0
----------------------------------
Закройте DocFlow, замените папку app\ новой из архива 1.2.0.
Папки data\, clients\, backups\ НЕ ТРОГАЙТЕ. База обновится
автоматически при первом запуске: добавятся пользователи
(включая админа), календарь и журнал, старые данные сохранятся.


ПОЛЬЗОВАТЕЛИ И ДОСТУП
---------------------
• Администратор: всё + раздел «Администрирование» (пользователи,
  журнал). На чистой установке сохраняется резервная учётная запись
  admin; её пароль рекомендуется заменить на известный только владельцам.
• Пользователь: всё остальное (клиенты, договоры, документы,
  матрица, рабочие документы, календарь, репозиторий, настройки,
  бэкап).
• Создать пользователя: Администрирование → «＋ Новый
  пользователь» → логин, имя, пароль (от 4 символов), роль.
• Зарегистрироваться под новым логином можно кнопкой «Регистрация»
  на экране входа. Такая регистрация создаёт обычную учётную запись
  без прав администратора.
• Забыли пароль пользователя: админ открывает его карточку (✎) и
  задаёт новый пароль.
• Уволился сотрудник: админ ставит «Активен: Нет» — вход станет
  невозможен, а его записи в журнале и документах сохранятся.
• Выйти / сменить свой пароль: клик по имени справа вверху.
• Приложение однопользовательское в момент времени: кто вошёл —
  под тем и идёт работа (журнал пишет действия на это имя).


КАЛЕНДАРЬ-ПЛАНЁР
----------------
• Клик по пустому дню — создать задачу на эту дату.
• Клик по задаче — просмотр/редактирование.
  Изменять задачу может только её автор или администратор; остальные
  пользователи могут видеть общую задачу и отмечать её выполненной.
• Поля: название, дата, время/дедлайн, ответственный (из списка
  пользователей), участники (отметки), описание, статус.
• «✓» в панели задач — отметить выполненной.
• Красная подсветка — задача просрочена и не выполнена.
• «Ближайшие задачи» — открытые на сегодня и далее;
  «Мои задачи» — где вы ответственный/участник/автор.


ЖУРНАЛ (для администратора)
---------------------------
Администрирование → вкладка «Журнал действий и посещений»:
время, пользователь, действие, объект, подробности. Фильтр по
пользователю, поиск по тексту, «Экспорт в CSV» (файл сохраняется
в backups\ и открывается в Excel). В журнале фиксируются: входы
(включая неудачные), выходы, создание/изменение клиентов,
контактов, договоров, генерация документов, смены статусов,
рабочие документы, задачи календаря, настройки, шаблоны,
пользователи, бэкапы.


РЕЗЕРВНОЕ КОПИРОВАНИЕ
---------------------
• Кнопка «Сделать бэкап сейчас» в Настройках — копия в
  backups\<дата_время>\ (база + документы + шаблоны). После создания
  копия автоматически проверяется; копии старше 30 дней удаляются.
• backup.bat — тот же безопасный бэкап из проводника или планировщика.
• Автоматически каждый день в 23:00 — выполните один раз
  в командной строке (подставьте свой путь):

  schtasks /Create /TN "DocFlow Backup" /TR "\"D:\DocFlow\backup.bat\" silent" /SC DAILY /ST 23:00 /F

• Восстановление: полностью закройте приложение и запустите
  restore.bat. Выберите копию из списка и введите слово
  ВОССТАНОВИТЬ. Перед заменой текущих данных программа автоматически
  создаст аварийную копию текущего состояния.


КАК РАБОТАТЬ (типовой сценарий)
-------------------------------
1. «Клиенты» → «＋ Новый клиент»: реквизиты, банк, руководитель
   (ФИО — автоматически просклоняется). Папка клиента создаётся
   сама.
2. Карточка клиента → «Контакты», «Договоры».
3. «＋ Новый договор»: номер предлагается автоматически, цена,
   предоплата, срок оказания услуг (раб. дней), дата выдачи АЗ
   (дата оригиналов подставится сама — за 5 раб. дней).
4. Генерация: вкладка «Документооборот» → «Создать из шаблона»
   или раздел «Создать документ». Файл попадает в
   clients\<Клиент>\<Год>\, статус «готов».
5. Статусы: готов → подписан → отправлен → получен (в карточке
   или кликом по ячейке матрицы «Общий документооборот»).
6. «Рабочие документы»: раздел, ассистент, аудитор, срок, статус.
7. «Календарь-планёр»: общие задачи, созвоны, дедлайны.

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
1. Забыли пароль админа: напишите разработчику — сброс делается
   одной командой (или удалением записи в таблице users при
   закрытом приложении — только если знаете, что делаете).
2. Запустите DocFlow-debug.bat — консоль с текстом ошибки.
3. Окно открылось, но внутри красная плашка — на ней текст ошибки.
4. Антивирус ругается на pythonw.exe в runtime — добавьте папку
   программы в исключения (это портативный официальный Python).
5. Ничего не запускается — проверьте, что папка распакована
   полностью (app\, runtime\pythonw.exe, bat-файлы).

Тесты для самопроверки (не требуют установки):
tools\test_backend.py, tools\test_migration.py, tools\test_template.py
